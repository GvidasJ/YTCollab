    About removing

    Remove from video takes that collaborator off the video in YouTube Studio. It runs in the profile where the uploading channel is signed in: the extension checks the signed-in channel, opens the video's Details page, and clicks that collaborator's remove control in the Collaboration section. Nothing else on the video is touched. With dry run on it only highlights what it would click.

    Remove from list only deletes the extension's record in this profile. YouTube is not touched.
